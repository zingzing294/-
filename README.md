# 텍스트 리더 (안드로이드)

txt 파일을 담아두고 읽는 앱입니다. 읽던 위치를 기억해서 앱을 껐다 켜도 그 자리에서 이어집니다.
인터넷 권한이 없어 완전히 오프라인으로 동작합니다.

화면과 기능은 전부 `app/src/main/assets/index.html` 한 파일 안에 있습니다.
같은 파일을 PC 브라우저에서 그냥 열어도 똑같이 동작합니다.

---

## APK 만드는 법 1 — GitHub (컴퓨터 사양 상관없음, 설치할 것 없음)

1. GitHub 에서 새 저장소를 만듭니다.
2. 이 폴더의 내용을 통째로 올립니다. (웹 화면에서 끌어다 놓아도 됩니다)
3. 저장소의 **Actions** 탭에 빌드가 자동으로 뜹니다. 3~5분 기다립니다.
4. 완료된 실행을 눌러 아래쪽 **Artifacts** 의 `txt-reader-apk` 를 내려받습니다.
5. 압축을 풀면 `app-debug.apk` 가 나옵니다. 폰으로 옮겨 설치합니다.

## APK 만드는 법 2 — 안드로이드 스튜디오

1. 안드로이드 스튜디오에서 **Open** 으로 이 폴더를 엽니다.
2. Gradle 동기화가 끝날 때까지 기다립니다. (첫 실행은 오래 걸립니다)
3. `Build > Build App Bundle(s) / APK(s) > Build APK(s)`
4. `app/build/outputs/apk/debug/app-debug.apk` 가 결과물입니다.

## 설치할 때

서명이 없는 개발용 APK라서 "출처를 알 수 없는 앱" 설치를 허용해야 합니다.
설정 > 앱 > 특별한 접근 권한 > 알 수 없는 앱 설치 에서 파일 관리자에 권한을 주면 됩니다.

---

## 내용을 고치고 싶을 때

거의 모든 것은 `app/src/main/assets/index.html` 만 고치면 됩니다.
색, 글꼴 목록, 검색 방식, 화면 구성이 전부 그 안에 있습니다.
코틀린 파일은 파일 선택기, 화면 켜두기, 백업 저장만 담당합니다.

## 만든 환경

- minSdk 26 (안드로이드 8.0 이상)
- targetSdk 34
- Gradle 8.7 / Kotlin 1.9.24 / AGP 8.5.2
